# محوّل التاريخ (هجري ⇄ ميلادي)

تطبيق أندرويد (Kotlin + Jetpack Compose) يحوّل بين التاريخ الهجري (أم القرى) والميلادي ويعرض اسم يوم الأسبوع.

## طريقة التشغيل
1. ثبّت **Android Studio** (الإصدار Koala أو أحدث).
2. افتح المجلد `HijriConverter` من File → Open وانتظر انتهاء مزامنة Gradle.
3. وصّل هاتفك (تفعيل خيارات المطور وتصحيح USB) أو شغّل محاكيًا، ثم اضغط Run.

## لإنشاء ملف APK
Build → Build Bundle(s) / APK(s) → Build APK(s)
الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات
- أقل إصدار أندرويد: 8.0 (API 26).
- النطاق المدعوم: من 12 نوفمبر 1882م (1 محرم 1300هـ) إلى 25 نوفمبر 2174م (30 ذو الحجة 1600هـ).
- التحويل يتم بمكتبة `java.time` المدمجة (HijrahChronology بتقويم أم القرى)، دون إنترنت.
